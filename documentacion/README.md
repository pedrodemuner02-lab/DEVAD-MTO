# 📚 Documentación del Proyecto DEVAD-MTO

Esta carpeta contiene la documentación completa del desarrollo e implementación del Sistema de Gestión de Mantenimiento DEVAD-MTO.

## 📑 Índice de Documentos

### 1. [CAPITULO-3-DESARROLLO.md](./CAPITULO-3-DESARROLLO.md)
**Documento principal del desarrollo del proyecto**

Capítulo 3 completo que describe la metodología y actividades realizadas para el diagnóstico, diseño e implementación del manual de mantenimiento y el sistema DEVAD-MTO.

**Contenido:**
- 3.1 Análisis de la Situación Actual
- 3.2 Diseño y Desarrollo del Sistema de Mantenimiento
- 3.3 Establecer un Programa de Mantenimiento Preventivo
- 3.4 Seguimiento y Mejora Continua
- 3.5 Implementar un Programa de Capacitación
- 3.6 Beneficios Esperados
- 3.7 Conclusiones del Desarrollo

### 2. [METODOLOGIA-DIAGNOSTICO.md](./METODOLOGIA-DIAGNOSTICO.md)
**Metodología de diagnóstico y análisis**

Documento complementario que detalla las fases del diagnóstico realizado en la planta.

**Contenido:**
- Fase 1: Reconocimiento de Instalaciones
- Fase 2: Observación de Prácticas Actuales
- Fase 3: Entrevistas con Personal Clave
- Fase 4: Análisis de Documentación Existente
- Fase 5: Clasificación de Equipos
- Fase 6: Identificación de Necesidades
- Justificación del Desarrollo del Sistema

### 3. [ESPECIFICACIONES-TECNICAS.md](./ESPECIFICACIONES-TECNICAS.md)
**Especificaciones técnicas del sistema DEVAD-MTO**

Documentación técnica completa del sistema desarrollado.

**Contenido:**
- Arquitectura del Sistema
- Stack Tecnológico (React, Vite, Tailwind, Supabase)
- Estructura de la Base de Datos
- Módulos del Sistema
- Servicios (Business Logic)
- Flujos de Trabajo
- Seguridad y Roles
- Deployment
- Roadmap Técnico

### 4. [PROGRAMA-CAPACITACION.md](./PROGRAMA-CAPACITACION.md)
**Programa completo de capacitación**

Plan detallado para capacitar al personal en el uso del sistema y el manual de mantenimiento.

**Contenido:**
- Objetivos y Alcance
- Estructura del Programa (Módulos 0, 1, 2, 3)
- Capacitación por Roles (Operadores, Jefe, Supervisores)
- Materiales de Capacitación
- Metodología de Enseñanza
- Evaluación y Certificación
- Seguimiento Post-Capacitación
- Medición de Éxito

## 🎯 Cómo Usar Esta Documentación

### Para Estudiantes/Tesistas
1. **Comience por:** `CAPITULO-3-DESARROLLO.md` - Es el documento principal que integra todo
2. **Profundice en:** Los documentos complementarios según el aspecto que necesite desarrollar
3. **Referencias técnicas:** `ESPECIFICACIONES-TECNICAS.md` para detalles de implementación

### Para Implementadores
1. **Entienda el contexto:** `METODOLOGIA-DIAGNOSTICO.md`
2. **Conozca el sistema:** `ESPECIFICACIONES-TECNICAS.md`
3. **Planee la capacitación:** `PROGRAMA-CAPACITACION.md`

### Para Usuarios/Operadores
1. **Visión general:** Sección 3.5 de `CAPITULO-3-DESARROLLO.md`
2. **Guía de capacitación:** `PROGRAMA-CAPACITACION.md` (Módulo 1)

### Para Administradores/Jefes
1. **Entendimiento completo:** Todos los documentos
2. **Enfoque especial:** `PROGRAMA-CAPACITACION.md` (Módulo 2)
